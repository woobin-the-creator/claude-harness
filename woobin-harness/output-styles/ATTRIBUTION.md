# 출처 — fluent-korean

이 디렉터리의 `fluent-korean.md` · `fluent-korean-not-coding.md` 는 자작이 아니라 **외부 산출물을
가져와서 일부만 덧붙인 것**이다. 나중에 "이 문구를 내가 왜 이렇게 썼지"라고 되묻지 않도록 남긴다.

| 항목 | 값 |
|---|---|
| 원본 | https://github.com/snflkd/fluent-korean |
| 가져온 커밋 | `59965eb8b81bee4b6aefdafc38812dd0b6a03317` (2026-08-19) |
| 라이선스 | MIT — 전문은 `LICENSE-fluent-korean` |
| 원본 경로 | `plugins/fluent-korean/output-styles/*.md` |

## 이 레포에서 바꾼 것

원본 지침 본문은 **한 글자도 고치지 않았다.** 원저자가 "어휘 priming을 조절하려고 지침 본문 자체도
그 지침을 준수해서 썼다"고 밝혔기 때문에, 본문을 손대면 의도한 효과가 무너질 수 있다.

바꾼 것은 원본 README가 "골라서 지침 끝에 덧붙이라"고 제시한 **선택 블록 3개를 붙인 것뿐**이며,
두 파일 모두 `## 추가 사항` 절 말미에 같은 순서로 들어 있다.

| 붙인 블록 | 고른 이유 |
|---|---|
| 희귀 어휘 자제 | 원본 README가 오푸스·페이블 사용자에게 권한 항목이다. 이 하네스의 기본 모델이 Opus 5다 |
| 모든 한국어 산출물에 적용 | 보고문뿐 아니라 `claude-blog-translate-ko` · `claude-youtube-to-blog` · `explain-in-html` 이 뱉는 한국어 산출물까지 규율 대상으로 삼는다 |
| 출력 직전 자기 점검 | 지침이 길어서 앞부분 조항이 흘려지는 것을 막는다. 대가는 사고 토큰 증가다 |

**일부러 안 붙인 것**

- 존댓말·호칭 블록 — 이 하네스의 전역 `CLAUDE.md` 와 문서 전체가 간결한 평서·명령형이라 어조가 갈린다.
- 초보 개발자용 블록 — 해당 없음.
- 문체 민감 작업 예외 블록 — "모든 산출물에 적용"과 짝이 되는 완충 장치다. 소설·대본·출제처럼
  별도 문체 지침이 있는 작업을 하게 되면 **이 블록을 먼저 붙여라.** 지금은 그런 작업이 없어서 뺐다.

## 갱신할 때

원본이 바뀌면 `git diff` 로 본문만 따로 비교해라. 위 표의 "붙인 블록 3개"는 이 레포 고유분이라
원본에 없다. 통째로 덮어쓰면 조용히 사라진다.

## 이름 충돌

원본 플러그인(`/plugin install fluent-korean@fluent-korean`)을 **같이 설치하지 마라.** 스타일 이름이
`fluent-korean` 으로 같아서 어느 쪽이 잡히는지 알 수 없어진다. 이 레포에 담은 이유가 그 모호함을
없애기 위해서다.
