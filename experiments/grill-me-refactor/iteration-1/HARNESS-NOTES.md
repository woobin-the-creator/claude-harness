# 이번 A/B의 환경 제약 (해석 시 반드시 감안)

1. **서브에이전트 모델은 sonnet이다.** 이 세션의 PreToolUse 훅이 model 미지정 Agent 호출을
   sonnet으로 고정한다(R3). 구본·신본 **양쪽 동일**하므로 비교는 공정하다. 다만 실사용(opus)보다
   지시 준수가 어려운 조건이라, 여기서 지켜지는 규정은 실사용에서도 지켜진다고 볼 수 있다.

2. **중첩 탐색 위임이 이 환경에서 작동하지 않는다.** 신본 스킬은 "코드 조사는 탐색 서브에이전트에
   위임"을 지시하는데, 서브에이전트가 띄운 손자 에이전트는 백그라운드로 돌고 결과를 못 돌려준다.
   해당 런은 "직접 조사하라"로 재개시켰다. **스킬의 결함이 아니라 평가 하네스의 제약이다** —
   실제 메인 세션에서는 위임 결과가 알림으로 돌아온다.
   대신 이 제약 때문에 "조사를 위임했는가"는 이번 채점에서 **점수 항목이 아니다.**
   실제로 채점하는 건 "묻기 전에 사실을 알아냈는가"(경로 인용 여부)다.

3. **질문 툴을 실제 호출하지 못한다.** 양쪽 모두 선택지를 본문에 적도록 지시했다. 따라서
   AskUserQuestion 도입의 왕복 절감 효과는 이번 벤치마크로 측정되지 않는다 → gh issue #20.
